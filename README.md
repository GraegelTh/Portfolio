# Thomas Grägel — Portfolio

My personal, interactive developer portfolio. A single-page site built around a
Windows PowerShell-inspired terminal aesthetic, showcasing my background, skills,
and projects as a Junior .NET Developer.

**Live sections:** hero terminal · about · stack matrix · projects · an interactive
faux CLI in the footer.

## 🤖 Agentic Workflow (Behind the Scenes)
To put my interest in AI-driven development into practice, the frontend of this site was entirely orchestrated and generated using **Claude Code**. Acting as the architect, I directed the autonomous terminal agent to scaffold the Vite application, write the React components, and apply the Tailwind styling. This project serves as a hands-on experiment in managing agentic development workflows and verifying AI-generated UI architecture.

## Tech Stack
- [React](https://react.dev/) — UI components
- [Vite](https://vite.dev/) — dev server & build tooling
- [Tailwind CSS](https://tailwindcss.com/) — styling
- [Framer Motion](https://motion.dev/) — animations & transitions
- [Lucide](https://lucide.dev/) — icon set
